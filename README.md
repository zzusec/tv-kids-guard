# TV Kids Guard · 电视时长管控

给安卓电视设置每天能看的时长。默认 30 分钟，用完自动锁屏，家长用遥控器管理。

## 安装

需要 Android 4.4（API 19）及以上，遥控器有方向键、OK 和返回键即可；没有数字键时可使用屏幕数字键盘。

1. 下载 APK，通过 U 盘或 ADB 安装。
2. 首次输入出厂密码 `000000`，再设置自己的 6 位家长密码。
3. 开启悬浮窗、无障碍服务，并允许应用在后台运行。

## 遥控操作

进入家长面板后，用方向键选择操作、按 OK 执行；有数字键的遥控器也可直接输入两位快捷码。

| 快捷码 | 操作 | 说明 |
| --- | --- | --- |
| `00` | 关闭面板 | 只退出页面，不改变防护状态 |
| `11` | 改密码 | 再次验证后设置新密码 |
| `12` | 修改每日时长 | 每天 1–1440 分钟 |
| `13` | 检查更新 | 下载并安装正式版更新 |
| `22` | 临时加时长 | 只加今天，每天累计最多 60 分钟 |
| `33` | 立即锁定 | 马上锁屏，取消“今天不限时” |
| `44` | 关闭防护 | 确认后停止管控，保留时长和密码 |
| `55` | 开启防卸载 | 启用设备管理员，增加直接卸载限制；仍需设置保护 |
| `99` | 启用防护 | 恢复普通管控，仅停用时显示 |

- 默认模式：未手动选择时，同一非虚拟 `InputDevice` 为 0–9 每个数字报告普通数字键或小键盘数字键支持，则隐藏屏幕数字盘，只显示实体输入区；未报告完整数字键或检测结果未知时显示数字盘，不按电视或遥控器品牌判断。
- 手动切换：系统 keymap 不一定对应遥控器实际按键，所有输入页均提供方向键和 OK 可达的「使用屏幕数字盘」或「使用遥控器数字键」按钮。选择只保存在本机 `tvguard_remote`，优先于自动检测；切换会重排输入区域，不留空白数字盘位置。
- 家长验证与输入弹窗：实体模式默认聚焦输入区，按方向下或右到「使用屏幕数字盘」，OK 展开；数字盘显示时，从盘顶部按方向上到「使用遥控器数字键」，OK 收起。
- 无数字键：用方向键在屏幕数字盘上选择数字，按 OK 输入；选择屏幕上的「删除」或「确认」按钮，再按 OK 执行。
- 有实体数字键：保留直接输入，输入后左方向键删除、OK 直接确认。
- 返回键取消当前输入。家长密码为 6 位且始终遮罩，时长显示数字，数字盘输入后选择「确认」保存；两种模式均不依赖系统输入法（IME）。家长验证、首次设置和修改密码、到时锁屏、每日时长与临时加时均支持这两种输入方式及手动切换；切换本身不更改 PIN、计时、失败冷却或授权规则。

锁屏默认聚焦「家长管理」按钮，按 OK 进入家长验证，验证后打开面板，不自动解除当天限时。从该按钮出发，数字盘显示时方向下或右进入数字盘、方向左到切换按钮；实体模式时方向下或右到切换按钮，OK 可展开数字盘，也可直接用遥控器数字键输入。输入家长密码并确认则**今天不限时**，次日恢复。返回取消输入不会解除锁定。修改每日时长或临时加时也会恢复限时，但不会清空今天已看时长。

## 注意

- 防护开启时按亮屏时间计时，不是视频播放时长；关屏和锁定时暂停，次日清零。
- 更新请覆盖安装，不要卸载或清除数据。Actions 中的 `community-debug` 包不能覆盖正式版。
- 日常保护依靠家长密码、到时锁屏和无障碍设置拦截：点击图标先验证，进入已识别的设置、应用详情或卸载页面时弹出验证页，返回不会露出原设置页。密码只输一次：验证通过后到本次授权结束前不会再要求输入密码、也不会被重新锁定，直到家长在面板按 `33 立即锁定`，或离开面板、授权到期后重新受保护。
- 无障碍服务重连及定时检查会查询当前窗口所属包名，恢复已打开页面的保护；不遍历控件，不读取、保存或上传界面文字。页面识别失败会重试；面板区分权限未开启、服务未连接和查询失败，不能把启用列表当作实际运行状态。升级后请家长确认无障碍服务正常连接；若被系统关闭，普通应用不能自行重新开启。
- `55 开启防卸载` 是附加保护，由家长在系统确认页启用普通设备管理员。管理员仍启用时，系统拒绝直接卸载，但部分设置页可以先停用管理员再卸载；停用后的密码提示不能撤销该操作。因此必须保持设置拦截正常，不能把普通管理员当成系统级密码卸载锁。
- 本轮不要求 root、刷机、系统预装或 Device Owner。普通保护不保证阻止系统强停、清除数据或厂商未覆盖的卸载入口，安装后须检查实际电视的桌面长按和应用管理入口。
- 关闭防护会解除设备管理员；再次启用防护不会自动恢复该身份，需要重新按 `55`。Android 4.4 同样支持设备管理员，但没有系统 Lock Task，不能承诺系统级防绕过。更新由旧版系统安装器确认，不会静默安装。
- 数据保存在电视本地，无需注册账号；更新需要连接 GitHub。不同厂商的后台限制可能影响计时，请安装后验证。

本轮版本为 2.5.8（versionCode 39），修掉 Sony BRAVIA 4K 2015 上「输入家长密码进入面板后又被要求输入密码」的死循环：半透明管理面板之下的设置页仍会上报自己是前台窗口，拦截服务便在面板之上反复拉起验证页，而面板退到后台会撤销本次授权。现在密码只输一次，家长界面在屏时拦截服务一律不动手。保留 2.5.7 按数字键能力切换的屏幕数字盘、手动选择优先及 Android 4.4 兼容路径。小米电视 2（MiTV2-40）的实机安装与遥控验收仍待 ADB 恢复后完成。
