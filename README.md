# TV Kids Guard · 电视时长管控

面向 Android TV 和安卓电视盒子的本地儿童时长管理工具。家长用实体遥控器设置每日额度、临时加时和管理密码，到达额度后自动锁屏。

不需要注册账号、手机配对或云端管理后台。日常计时、密码验证和规则保存在电视本地；检查与下载更新需要联网。

家长管理面板采用 [Preline](https://github.com/htmlstreamofficial/preline) 启发的低亮度深灰设计，适合电视观看距离与方向键操作。上图为原生渲染预览，使用示例数据；展示了“今天不限时”、临时加时以及未授权时的提醒，不包含真实密码或设备信息。

## 主要功能

- **每日观看额度**：默认 30 分钟，可设为 1–1440 分钟；当天用量按电视本地日期进入新一天后重置。
- **统一亮屏计时**：防护开启时，不依赖特定视频应用，屏幕开启且未锁定即累计时间；关屏和锁定期间暂停计时。
- **到时锁定与倒计时**：显示剩余时长，到达额度后进入锁屏；悬浮显示依赖对应系统权限。
- **仅今天临时加时**：每天累计最多增加 60 分钟，不修改每日额度，次日自动清零。
- **家长密码与遥控操作**：6 位数字密码、输入遮罩、输错冷却；仅使用遥控器实体数字键，没有屏幕数字键盘或系统软键盘。
- **后台恢复与应用内更新**：定期保存当天用量，支持开机恢复；通过家长面板检查更新，并验证升级包的包名、版本、SHA-256 和签名。

**计时不是“识别视频播放时长”**：防护开启时，停留在桌面、浏览设置或打开其他应用，只要屏幕开启且未锁定，也会计入用量。系统休眠、厂商后台限制等可能影响服务运行，安装后应在自己的电视上验证。

## 快速开始

### 1. 确认设备与遥控器

- 最低系统要求为 Android 5.0（API 21）；项目已在 Sony BRAVIA、Android 7.0（API 24）上使用和验证，其他厂商固件仍需自行确认兼容性。
- 遥控器需要提供 **0–9 数字键、方向键、OK 和返回键**。当前没有为不带数字键的精简遥控器提供屏幕键盘替代方案。
- 这是家长辅助工具，不是无法绕过的系统级管控方案；实际防护能力取决于电视固件、授权和应用是否持续运行。

### 2. 安装正式版

从 [Releases](https://github.com/zzusec/tv-kids-guard/releases/latest) 下载 `tv-kids-guard.apk`，通过 U 盘、文件管理器或自己的 ADB 连接安装。按电视提示允许对应来源安装应用。

已连接并授权 ADB 的用户也可以执行：

```bash
adb install -r tv-kids-guard.apk
```

更新时请直接覆盖安装，**不要先卸载、清除应用数据或恢复出厂设置**。包名为 `com.family.tvguard`；正式版需要保持同一签名才能覆盖升级。

### 3. 设置家长密码

首次安装，使用出厂密码 `000000` 完成验证，再按提示输入并确认新的 6 位家长密码。应用要求更换出厂密码后才能进入管理面板；后续进入使用自己的密码。

密码只显示圆点，输入满 6 位自动提交；左方向键删除一位。请妥善保存密码，连续输错会触发冷却等待，不要反复猜测。

### 4. 检查权限并设置额度

在电视系统设置中按需要授权，回到家长面板确认提示，再用 `12 修改每日时长` 设置额度。不同电视的设置名称和入口可能不同。

| 授权或设置 | 作用 | 注意事项 |
| --- | --- | --- |
| 显示在其他应用上层 / 悬浮窗 | 剩余时长提示与锁屏遮罩 | 未开启时面板会提示，相关显示能力会受影响 |
| 无障碍服务 | 对设置、应用详情及卸载等相关入口触发家长验证 | 需要在系统中手动开启；不能保证覆盖所有厂商入口 |
| 自启动 / 后台运行 | 帮助开机恢复并保持计时服务运行 | 部分厂商需单独放行，安装后验证关屏、开机和后台运行 |
| 安装未知来源应用 | 安装 APK 和应用内升级 | 按系统提示授权；部分旧版电视使用全局开关 |
| 通知权限（Android 13+） | 计时服务通知 | 按系统提示授权 |

**普通安装不等于系统级防卸载。** 无障碍入口保护与设备所有者（Device Owner）策略是不同能力，具体边界见下文。

## 遥控器操作

### 管理面板快捷码

进入家长面板后，可以直接输入两位数字，也可以用方向键选择按钮、按 OK 执行。不可用操作会隐藏，输入对应快捷码也不会执行。

| 快捷码 | 操作 | 效果 |
| --- | --- | --- |
| `00` | 关闭面板 | 只退出管理页、结束家长会话，不改变防护开关和既有规则 |
| `11` | 改密码 | 再次验证家长密码后，设置并确认新密码 |
| `12` | 修改每日时长 | 修改每天的观看额度，输入分钟数后按 OK 保存 |
| `13` | 检查更新 | 检查、下载并安装正式版更新，按系统提示授权或确认 |
| `22` | 临时加时长 | 只增加今天的时长，不改变每日额度；每天累计上限 60 分钟 |
| `33` | 立即锁定 | 立即结束本次观看，并取消“今天不限时”状态 |
| `44` | 关闭防护 | 确认后停止管控，并尝试解除应用的设备管理策略，保留密码和时长设置 |
| `99` | 启用防护 | 重新启用时长管控；只在防护关闭时显示 |

### 密码与时长输入

- **密码**：用数字键输入，满 6 位自动验证；左方向键删除一位。
- **时长**：输入分钟数，按 OK 确认；仅输入数字不会保存，返回键取消。
- **返回键**：在管理面板中退出面板，在输入弹窗中取消；在到时锁屏中不会解除管控。
- **音量与电源键**：仍交由电视系统处理，不被家长面板或锁屏当成密码输入。

### 到时锁屏：进入后台与今天不限时

锁屏没有输入数字时，按 **OK** 打开家长验证，验证后进入管理面板。**进入后台本身不会让今天不限时**；如果只想增加少量时间，请进入后台后使用 `22 临时加时长`。

如果在到时锁屏上直接输入已设置的家长密码，则会解除锁定，并让**今天剩余时间不限时**。这不会修改每日额度，也不等于关闭防护；次日自动恢复按每日额度管控，需要提前结束观看时可使用 `33 立即锁定`。

修改每日时长或临时加时也会退出“今天不限时”，恢复按额度管控；这两项操作都不会清空今天已用时长。

## 更新与卸载

### 更新

在家长面板使用 `13 检查更新`，或从 Releases 下载正式 APK 覆盖安装。应用支持后台安排检查与下载，安装过程仍需在家长授权下按系统提示完成，不应把它理解为绕过系统安装限制的静默升级。

升级包必须满足包名、版本、大小、SHA-256 和已安装应用签名等校验。网络无法访问 GitHub 或下载失败时，可以改用手动下载与覆盖安装；不要为了升级成功先清除数据。

Releases 同时提供 `update.json` 与 `SHA256SUMS`。需要手动校验时，将同一版本的 `tv-kids-guard.apk`、`update.json` 和 `SHA256SUMS` 三个文件下载到同一目录，再进入该目录执行：

```bash
# macOS
shasum -a 256 -c SHA256SUMS

# Linux
sha256sum -c SHA256SUMS
```

GitHub Actions 的 `community-debug` 构建是开发测试包，**不是正式 OTA 包**。其签名与官方正式版不同，不能直接覆盖正式安装；开发测试请使用单独的测试设备或模拟器。

### 关闭防护与卸载

先在家长面板使用 `44 关闭防护`，阅读并确认结果，再通过系统正常卸载。如果提示“解除未完成”，应保留当前配置核查原因，不要把它当成已经成功解除。

关闭防护不会清除密码和额度。重新使用 `99 启用防护` 可以恢复普通时长管控，但**不会自动重新授予已解除的 Device Owner 身份**。

## 防护边界与常见问题

### 能完全防止卸载、强停和清除数据吗？

不能对所有电视做此承诺。普通安装依靠应用持续运行、悬浮显示和无障碍入口保护；只有在设备确实支持并已成功配置 Device Owner 时，才能应用相应的系统管理限制，且不同 Android 版本与厂商固件仍有差异。

仓库提供只读预检工具，供已建立自有 ADB 连接的家长或开发者核查能力：

```bash
bash tools/device_precheck.sh "<ADB_SERIAL>"
```

该脚本不会安装应用、设置 Owner、删除账户或重置电视。**支持设备管理不代表一定可以开通 Owner，不要为试错恢复出厂。** 本工具不能保证抵御具有 ADB、Root、恢复出厂或固件修改权限的人。

### 为什么超过每日额度仍然能看？

先查看面板是否显示“今天不限时”或“防护已关闭”，再检查实际运行和权限提示。今天不限时可能来自在到时锁屏上输入家长密码，不是修改了每日额度。

### 为什么进入后台还要输入密码？

关闭面板或离开家长界面后，家长会话会结束。重新验证是正常的保护流程，不代表密码或时长设置丢失。

### 会收集观看记录或上传家长密码吗？

当前应用将密码哈希、额度、用量等保存在本机，不提供账号、云端同步或观看记录上传接口。更新检查与下载会访问 GitHub；无障碍服务用于判断受保护的系统设置入口。请勿在 Issue、截图或日志中公开自己的密码、签名私钥和调试凭据。

## 开发与构建

环境要求：JDK 17、Android SDK 35、build-tools 35.0.0、Python 3。项目自带 Gradle Wrapper；通过 `ANDROID_HOME` 或 `local.properties` 的 `sdk.dir` 指定 SDK。

```bash
# Android 单元测试与开发包
./gradlew testDebugUnitTest assembleDebug

# 发布工具测试，不需要正式签名私钥
python3 -I -B -m unittest discover -s tools -p 'test_*.py' -v

# 重新生成同目录的独立 HTML 说明
python3 -I -B tools/md_to_html.py
```

开发包位于 `app/build/outputs/apk/debug/app-debug.apk`。没有私有正式签名配置时，开发构建使用开发签名；正式包的构建、证书校验和发布步骤见 [开发与发布说明](docs/开发说明.md)。不要将签名私钥或密码提交到仓库。

测试覆盖密码与会话、遥控器数字键和 DPAD、临时加时、更新校验，以及 720p / 1080p / 4K、窄屏滚动与放大字号等布局场景。自动化布局与原生渲染预览不能代替所有厂商电视上的实机验收。
