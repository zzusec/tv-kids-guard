tv-kids-guard

Platform

android；原生 Android TV，Java 与 XML Views。

目标与使用场景

帮助家庭管理孩子每天看电视的时间。家长在 Android TV 上使用实体遥控器进入管理面板，查看今天已看时长、每日额度与防护状态，调整规则或处理当前观看。

已确认的交互约束

  • Android 原生 Java/XML，不用网页或 WebView 代替电视界面。
  • 2.5.7（versionCode 38）按数字键能力决定输入模式：按设备报告的普通数字键或小键盘数字键判断，检测结果未知时显示数字盘，不按品牌硬编码。
  • 2.5.9（versionCode 40）确定「每次进设置都要密码」规则：进入已识别的设置、应用详情或卸载页面都要重新输入家长密码，已授权的会话不作为通行证。防死循环靠另一条规则实现：验证页或管理面板正在屏幕上时，拦截服务一律不再拉起验证页或锁屏。管理面板是半透明窗口，其下的设置页仍会上报前台窗口，因此不能把前台判定当作「孩子进了设置」。
  • 2.5.10（versionCode 41）确定「待机不计时」：当天额度只按亮屏观看时间扣，计时基线用开机时长（uptimeMillis，深度休眠期间不前进），单个计时周期封顶 4 秒，主线程被卡住或计时事件补跑都不能一次扣掉整段挂钟差。同一版本还要求右上角角标不消失，是防护仍在运行的凭据；角标的具体形态由 2.5.12 收敛为只有倒计时。
  • 2.5.11（versionCode 42）把遥控器数字键识别改成「合起来算 + 实测说了算」：所有非虚拟键盘/方向键 InputDevice 报告的数字键取并集，覆盖 0–9 就隐藏屏幕数字盘，只显示实体输入区，单台设备报不全不再算「没有数字键」；并集缺一字或检测结果未知时显示数字盘。真的收到一个来自非虚拟设备的数字按键，就记下 physical_digits_seen 并收起数字盘——屏幕数字盘自己产生的按键和虚拟设备不算证据。判定不按电视或遥控器品牌硬编码。该版本还允许家长手动选择「使用屏幕数字盘」并记为 pad_pinned；这份偏好随 2.5.13 删除切换按钮一并取消。
  • 2.5.12（versionCode 43）去掉「今天不限时」：家长密码只证明家长在场，不是一天的免限时。在锁屏输入正确密码只打开家长管理面板，锁屏仍在面板之下，离开面板即恢复（2.5.17 起这条「立刻恢复」改成家长退出面板后的宽限，宽限同样不送时长，见下）；能给孩子更多时间的只有面板的 22 临时加时长 和 12 修改每日时长。右上角角标因此只有一种形态——未锁定时始终显示「剩余 MM:SS」，不再有琥珀色「今天不限时」；管理面板也不再显示「今天不限时」那一行。旧版写在设置里的不限时标记在升级后第一次读取时被删除，当天正处于不限时的电视立刻重新计时，不需要家长再做任何操作。
  • 2.5.13（versionCode 44）删除「使用屏幕数字盘 / 使用遥控器数字键」切换按钮：Sony 实机反馈是遥控器本身有数字键，屏幕上却还挂着这颗按钮，家长把它当成多余选项。输入方式从此只由硬件决定——数字键并集覆盖 0–9 或本机已实测到过真实数字键就用遥控器直接输入并隐藏数字盘，能力缺一字或未知才显示数字盘；验证页、到时锁屏、首次设置与改密码、每日时长、临时加时都没有切换入口，也没有任何组合键能打开数字盘。旧版写在 tvguard_remote 里的 show_keypad、pad_pinned 在升级后第一次读取时被清除，不把数字盘留在已具备数字键的电视上。
  • 2.5.14（versionCode 45）把「判定不出来就铺一屏数字盘」改成图标：数字键并集覆盖 0–9 或本机已实测到过真实数字键时，屏幕上既没有数字盘也没有图标，只有实体输入区；判定不出来时输入区下方只给一个数字键盘图标，方向键选中、按 OK 才展开数字盘，图标随盘收起。数字盘只属于当前这一屏，换一屏重新从图标开始，不做持久化。冷却或服务正在恢复导致数字盘不可用时，图标一起收起，方向键仍停在原入口，不让家长点开一个不能用的盘。2.5.13 的「删除切换按钮、清除 show_keypad/pad_pinned」全部保留。
  • 2.5.15（versionCode 46）确定「家长退出后台到桌面时豁免锁屏」：Sony 实机反馈是在锁屏输入家长密码进入家长后台后按返回键，又被送回输入密码的界面。现在返回键（与 00 关闭面板 同一条出路）把遥控器交给电视机自己的桌面，桌面这一屏不弹锁屏、不盖黑屏。豁免只属于刚退出后台的家长，且只有一步宽：桌面之外的第一个窗口立刻花掉它，锁屏随即回来；孩子自己在锁屏按 HOME 或返回到桌面拿不到豁免；33 立即锁定、验证页返回、屏幕熄灭待机都不产生豁免，重新亮屏先看到锁屏。豁免不改变今天已看时长、每日额度与锁定状态，也不给任何观看时间。无障碍设置拦截未连接时拒绝发放豁免，因为没有谁来结束它，退出面板照旧回到锁屏。这份一步式豁免已由 2.5.17 的家长宽限替换。
  • 2.5.16（versionCode 47）把「待机不计时」的判据换成两个部件同时作证：电源管理说屏幕亮着、并且显示子系统报告面板处于 STATE_ON，两者缺一都不计入当天时长；doze、屏保、面板熄灭而电源管理仍以为亮着的时段从此不再计费。同一版删掉锁屏的强制保持亮屏：管控自己不许电视进入待机，就等于把待机时间算给孩子。判定不按品牌硬编码，读不到面板状态的设备退回电源管理单一判据（该接口自 API 20 起才有，Android 4.4 上仍是单一判据），任何情况下都不会因为读不到而冻结额度。本版不新增、不修改任何时长数字：每日额度、临时加时、今天已看与锁定规则全部照旧。
  • 2.5.17（versionCode 48）把 2.5.15 的一步式桌面豁免换成「家长宽限」：Sony 实机反馈是家长在锁屏输过密码、进入后台、按返回退出后再进任何一个 APP，仍然被要求输入密码，成了死循环——桌面豁免只有一步宽，离开桌面的第一个窗口就把它花掉，而家长会话只有 3 分钟。规则改为家长从后台退出（返回键或 00 关闭面板）时给出一次宽限，到下一次待机或关机为止：这段时间锁屏不抢前台，系统设置页也不再每次都弹密码（这是 2.5.9 唯一被家长明确让步的例外）。宽限只由这几件事结束：待机或关机、33 立即锁定、跨到新一天、电视断电重开；结束的瞬间锁屏回来。宽限不送时长也不停表——期间面板亮着照常计入今天已看，每日额度与临时加时的数字一个不改，右上角显示「剩余 00:00」，因此它不是 2.5.12 删掉的「今天不限时」。宽限写在本地存储，管控进程被回收重启也不丢；没有家长输入过密码就不存在宽限，孩子自己在锁屏按 HOME 仍然立刻被锁。
  • 系统 keymap 不等于遥控器实际按键，因此判定同时看能力报告与实测按键；探测出现异常时按「未知」处理，数字盘退到图标后面而不是占满屏幕，不能让家长验证页崩溃。2.5.13 起不再有手动切换，家长不需要也不被提供覆盖检测的入口。
  • 2.5.7 起恢复日常密码拦截，不要求系统预装、root、刷机或 Device Owner：时间耗尽保持锁定；点图标先验证家长密码；进入已识别的设置、应用详情和卸载页面时拉起家长验证，返回不露出原设置页。
  • 设置保护依赖无障碍服务实际连接。重连和定时回查会查询当前窗口所属包名，不遍历控件、不读取或保存文字；厂商页面解析失败要重试，未知前台包变化要重新识别。面板区分权限未开启、服务未连接和查询失败，不把启用列表当作运行状态。
  • 家长会话不等于设置通行证：家长离开面板、会话到期后，同一个设置页重新要求密码，唯一的例外是 2.5.17 的家长宽限——刚退出面板的那段时间设置页一并放行，宽限结束重新要密码；面板在屏期间不重复弹出验证页或锁屏，家长主动 33 立即锁定 只恢复时长锁屏。系统激活和更新安装仅在显式、限时维护授权下放行，返回或到期后恢复拦截。面板 55 提供可选的设备管理员附加保护，不静默激活；普通管理员只能限制直接卸载，系统仍可先停用再卸载，不能把停用后的验证提示当成硬拦截。
  • 家长验证与输入弹窗在检测到数字键时默认聚焦输入区，直接用遥控器数字键输入；判定不出数字键时同样聚焦输入区，需要数字盘就按下键选中数字键盘图标展开，再用方向键在盘内选择、OK 输入。
  • 展开后的数字盘使用方向键选择数字、OK 输入，「删除」「确认」均有屏幕按钮。两种输入方式均不依赖系统输入法（IME），数字盘与其图标隐藏时都不保留空位。
  • 家长密码为 6 位数字且始终遮罩，失败冷却和授权边界不变；选中图标、展开数字盘或移动焦点都不代表通过验证。
  • 实体数字键输入继续保留，输入后左键删除、OK 直接确认；返回取消当前输入，不授予权限或解除锁定。
  • 管理面板支持两位数字快捷码，也支持方向键选择、OK 确认；修改密码需再次验证家长密码。
  • 时长输入显示数字，通过屏幕「确认」按钮或实体数字键输入后的 OK 确认；临时加时只对今天生效，不更改每日额度。

锁屏默认聚焦「家长管理」按钮，按 OK 进入家长验证，验证成功后仅打开管理面板。从该按钮出发，数字键已检测到时屏幕上没有数字盘也没有图标，直接按数字键即可，锁屏在任何焦点位置都收得到数字；判定不出来时，按方向下或右选中数字键盘图标，按 OK 才展开数字盘。在锁屏直接输入家长密码并确认同样只打开管理面板：不送出一天的时长，锁屏仍在面板之下，返回取消输入也不会解除锁定。

管理操作

快捷码 操作 含义
00关闭面板退到电视机桌面，防护状态不变；与返回键同一条出路
11改密码再次验证后设置新的家长密码
12修改每日时长修改每天的观看额度
13检查更新检查并安装应用更新
22临时加时长只增加今天可看的时长
33立即锁定立即结束本次观看
44关闭防护经确认停止管控，保留时长和密码设置
55开启防卸载在系统确认页启用设备管理员，增加直接卸载限制；仍需设置保护
99启用防护恢复已保存的管控规则

操作按真实状态显示，隐藏操作不能通过快捷码绕过可用性检查。概览保持精简，但真实的权限、服务和更新错误必须保留。

设计范围

家长管理面板采用 Preline 启发的克制暗色界面，原有卡片对齐和布局不变。用户已拒绝过亮、刺眼的浅色方向；验证门页和锁屏保留已有独立主题及授权语义，仅补齐原生数字盘交互。具体原生视觉规范见 DESIGN.md。

小米电视 2 的实机遥控验收仍待 ADB 恢复，不将自动化结果或原生渲染预览表述为小米实机验证。
